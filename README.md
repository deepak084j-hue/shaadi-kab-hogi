# Shaadi Kab Hogi? 💍

A funny, mobile-first Hindi/Hinglish wedding-prediction game. It is a static website: no login, backend, API key, paid service, or external library is required.

## Features
- Responsive premium dark-purple/pink UI
- Funny deterministic predictions based on form choices
- Wedding year, love-story style, venue, food ritual, partner energy, and rishtedaar-pressure meter
- Animated reveal, confetti, optional sound effects
- Native share on supported phones, clipboard fallback elsewhere
- Accessible labels, keyboard focus styles, reduced-motion support
- All prediction processing happens in the browser; form data is not sent anywhere

## Publish free with GitHub Pages
1. Create a new public GitHub repository, e.g. `shaadi-kab-hogi`.
2. Upload `index.html` to the repository's **root** (the top level, not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait a minute or two. GitHub will show the live website URL in the Pages section.

## Test before uploading
Open `index.html` in a modern browser. For the most accurate mobile sharing behavior, use the deployed HTTPS GitHub Pages URL.

## Notes
This is a comedy game, not astrology or a real prediction. The result should not be used for real-life decisions. The app has no external dependencies and works offline after the file is loaded.
